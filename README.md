# أوردرات بشندي — شاشة التابلت

شاشة إدارة الأوردرات — المطعم بيفتحها على متصفح التابلت (مش أبلكيشن بيتنزّل).

```bash
npm install
npm run dev     # http://localhost:5175
```

**الدخول:** إيميل وباسورد الأدمن/الموظف (نفس حساب الباكند).

## بتعمل إيه؟

- بتجيب الأوردرات من الباكند وبتتحدّث **كل 8 ثواني** لوحدها
- أوردر جديد → **نغمة تنبيه** + تبويب "جديد" بينبض
- كل كارت فيه: رقم الأوردر، الوقت، المصدر (موقع/واتساب)، النوع (توصيل/استلام)،
  **اسم العميل ورقمه (ضغطة = اتصال) وعنوانه كامل**، الأصناف باختياراتها،
  ملاحظة العميل مظللة، والإجمالي
- الأزرار حسب الحالة: اقبل → ابدأ التجهيز → جاهز → اتسلّم (+ إلغاء بخطوتين)

## تأكيد الواتساب

أول ما تدوس **"اقبل الأوردر"** بيفتح واتساب على رقم العميل برسالة تأكيد
جاهزة فيها الأصناف والإجمالي والعنوان — تدوس إرسال وبس.
(زرار 💬 في الهيدر بيقفل/يفتح الفتح التلقائي)

لما حساب WhatsApp Business API يتجهّز، السيرفر هيبعت نفس الرسالة
**تلقائيًا** من غير أي ضغطة — الكود جاهز في الباكند ومستني المفاتيح.

## الإعدادات

`.env.local` → `VITE_API_URL` عنوان الباكند (بعد الرفع: عنوان Railway).
